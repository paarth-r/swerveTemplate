# swerveTemplate (FRC 9974)

CTRE Phoenix 6 swerve drivetrain (generated by Tuner X) with Choreo autos.

## Making or editing an auto

1. Open the Choreo app and open `src/main/deploy/choreo/FRC-9974-Freshmen.chor`.
2. Add or edit a path, then click **Generate**.
3. Save, then deploy the robot code.
4. Pick the path by name from **Auto Chooser** on the dashboard.

Every `.traj` file in `src/main/deploy/choreo/` shows up in the chooser automatically.
No code changes are needed to add a new auto.

## Things to know

- **Always blue alliance.** Paths are never mirrored for red, and field-centric driving
  always uses the blue perspective. Draw every path from the blue side of the field;
  the robot runs it the same way on either alliance.
- **Start position matters.** At the start of an auto, odometry is reset to the path's
  first point, so place the robot exactly where (and facing how) the path starts.
- **Robot config.** Mass, moment of inertia, and bumper sizes in the Choreo project are
  placeholders. Measure the real robot, update them in Choreo's robot config, and
  regenerate all paths.
- **Path-following gains** are in `CommandSwerveDrivetrain.java` (`m_pathXController`,
  `m_pathYController`, `m_pathThetaController`).
- ChoreoLib is pinned to 2026.0.3 to match the Choreo app. Keep the app and the
  vendordep on the same version.
